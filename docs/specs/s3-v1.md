# S3-style object contract v1

A bucket name is globally unique within Commons, 3–63 lowercase ASCII bytes, starts and ends with an
ASCII alphanumeric, and otherwise permits only alphanumerics and `-`. Object keys are 1–1,024 bytes
and contain no NUL. Content type is at most 256 bytes. User metadata contains at most 64 pairs, keys
at most 128 bytes, and values at most 256 bytes.

ETag is the 64-character lowercase hexadecimal canonical BLAKE2b-256 content digest; it is never MD5.
List order is unsigned byte lexicographic, a page contains at most 100 objects, and its cursor binds
snapshot version plus last key.

PUT requires `operation_id` and optionally `if_match`. A mismatch is `S3_PRECONDITION_FAILED`. DELETE
creates a tombstone; GET of a tombstone is `S3_NOT_FOUND`. Versioning controls whether the previous
object version enters the bounded 64-item history, but the tombstone always retains its canonical
manifest and provider commitment until purge. Pruning requires no active Drive/root reference and
satisfaction of the deletion evidence window.

Bucket deletion is empty-first and constant-bounded. Object keys are enumerated from canonical
object storage for runtime-API listing rather than retained in a monolithic on-chain bucket index.
After DELETE, versioned history must be pruned and the tombstone must be removed with
`purge_object`. Purge applies the same fail-closed Drive-reference and canonical provider-deletion
evidence checks as history pruning before it erases the tombstone or operation authority; only then
does it delete at most the bounded 65 operation records and decrement the bucket object count.
`delete_bucket` succeeds only when that count is zero.

`operation_id` is a bucket-scoped pallet authority for idempotency. An exact PUT or DELETE retry is
side-effect-free and emits no duplicate event; reuse with different inputs fails with
`OperationIdConflict`. Results are retained for the live object and its bounded 64-version history,
then removed atomically when the corresponding history or tombstone is pruned.
