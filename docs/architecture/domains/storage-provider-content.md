## Activation rule

All source semantics must be classified in the contract-to-native ledger before implementation. Activation requires 21/21 machine evidence, zero unknown authority/semantic, native Rust and TypeScript coverage, and the M9 zero-survivor cleanup verdict. A new-genesis pallet may mark migration `not-applicable: no post-genesis schema transition exists yet`; it still declares storage version and future-upgrade policy.
