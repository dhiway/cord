# `@cord-network/origin-sdk-names`

Typed, finalized access to the native Commons Names pallet: commit/reveal registration, renewal, transfer, controllers, address/subject/attestation/content/text records, primary names, and finalized events.

The package exposes native metadata bindings only. Registrar, namespace-policy, pause, and forced calls are deliberately excluded from the application client and listed in `NAMES_ADMIN_EXCLUSIONS`.
